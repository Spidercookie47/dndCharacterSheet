# SRD 5.1 content pack

`index.json` lists the files that make up the pack. Each file has `elements` (or `info` / `tables`), in the same format any homebrew pack uses (see the top-level README).

This work includes material taken from the System Reference Document 5.1 ("SRD 5.1") by Wizards of the Coast LLC, available at https://dnd.wizards.com/resources/systems-reference-document. The SRD 5.1 is licensed under the Creative Commons Attribution 4.0 International License, available at https://creativecommons.org/licenses/by/4.0/legalcode.

Short feature summaries, the trinket list and the structured rule fields are original work added for this app. Long write-ups for races and classes come from the SRD and from text supplied by the project owner.
